# Methodology

Official lists must be independently curated, traceable, reviewed for the named language variety, and validated from source records. Project-created examples exercise tooling but are not security releases.

Do not copy or mechanically filter third-party dictionaries or word databases and claim the output is CC0. Record provenance and review license compatibility before ingestion or release. Deterministic tooling makes a release reproducible; it does not establish linguistic quality or licensing rights.
