# Licensing and provenance

Source code, tests, tooling, and documentation use the MIT license. Independently collected, explicitly eligible LexiForge datasets are intended for CC0 1.0 Universal only where contributors and the project have the right to make that dedication.

Released dataset licensing is distinct from software and documentation licensing. Third-party sources keep their own licenses and attribution obligations. Arbitrary derived lists cannot simply be relicensed as CC0; provenance and source terms must be reviewed before release. M0 bundles no third-party word dataset.
